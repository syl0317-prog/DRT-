# 위례선 트램·버스 300m 기본 / 500m 보조 대시보드

기존 Python, CSV, Excel은 변경하지 않고 `wirye_tram_bus_dashboard_500m.py`를 추가했습니다.
API 호출 및 .env 접근 없이 저장된 실제 API 진단 결과를 사용합니다.

## 실행

프로젝트 폴더의 PowerShell에서 다음 명령을 실행하세요. 현재 기본 python은 3.7이므로, 필요한 패키지가 설치되어 있는 Python 3.12를 명시합니다.

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -B -m streamlit run .\wirye_tram_bus_dashboard_500m.py
```

터미널에 안내되는 Local URL을 브라우저에서 여세요. 종료는 Ctrl+C입니다.

집계 검증만 실행하려면:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -B .\wirye_tram_bus_dashboard_500m.py --verify
```

검증 명령은 타임스탬프가 붙은 새 JSON 보고서만 생성합니다. 데이터는 덮어쓰지 않습니다.

## 데이터와 해석

- 기본 분석: 기존 300m CSV의 거리와 `d ≤ 300m` 기준 유지.
- 보조 분석: `300m < d ≤ 500m`. 500m 초과 데이터는 지도·집계에서 제외.
- 현재 성공 진단: `diagnostics_105_106_20261020_135343_283718`의 105번 2건, 106번 6건.
- 정거장별 최신 성공 진단을 선택하며, 실패한 실행이 과거 성공 자료를 대체하지 않습니다.
- 성공 상태, 전체·반환·상세 건수 일치, 트램 좌표 일치를 확인합니다.
- API 반환 정류장을 다른 트램 정거장과 임의로 연결하지 않습니다.
- 107~112번의 보조 구간은 **미수집**이며 0개가 아닙니다. 향후 같은 형식의 성공 진단 파일이 생기면 자동 반영됩니다.
- 300m 파란 실선 / 500m 주황 점선. 버스 마커는 기본 구간 파란색, 보조 구간 주황색.
- 동일 버스 ID는 지도에 한 번만 표시합니다. 선택된 연결 중 기본 구간 연결이 하나라도 있으면 파란색입니다. 팝업에 모든 연결·거리를 표시합니다.
- 동일 트램 번호·버스 ID는 하나의 연결 관계로 집계합니다. ID가 없는 경우 좌표를 식별자로 사용합니다.
- 위쪽 지표·지도·상세 목록은 선택한 거리 구간을 따릅니다. 정거장별 비교표·그래프는 선택한 트램의 두 구간을 항상 비교합니다.
- 트램 좌표는 **지도 추정값**입니다. 300m·500m는 **직선거리이며 실제 보행거리가 아닙니다**.
- 기존 미정차 지점은 원본대로 표시합니다. 승하차 가능한 정류장인지 별도 확인해야 합니다.

## 검증 결과

| 범위 | 300m 이내 연결 | 300m 초과~500m 연결 | 고유 정류장 |
|---|---:|---:|---:|
| 전체 | 35 | 8 | 35 |
| 105·106번 | 0 | 8 | 6 |

105번 보조 구간 2개, 106번 6개를 확인했습니다. 전체 43개 연결 관계에서 고유 정류장은 35개이며, 추가 연결 관계는 8개입니다.

거리 경계(정확히 300m·500m), 중복 제거, 선택 정거장별 마커 분류, 빈 데이터, 미수집 표시, 원본 해시 보존 검증을 통과했습니다.
Streamlit AppTest에서 초기 화면, 105·106 필터, 빈 거리 구간·정거장 선택을 오류 없이 확인했습니다.
지도 객체의 원 반경·점선·색상·고유 마커 수를 별도로 확인했습니다. 실제 브라우저에서 지도 타일 로딩과 화면 배치는 육안 검증하지 않았습니다.
