# 📊 Data Directory Guide

본 디렉토리는 위례신도시 DRT(수요응답형 대중교통) 최적 경로 및 교통 사각지대 분석을 위한 원천 데이터(`raw/`)와 전처리 가공 데이터(`processed/`)를 관리합니다.

> **주의 사항**
> - `data/raw/` 디렉토리는 대용량 원본 파일 보존을 위해 `.gitignore`에 등록되어 Git 추적에서 제외됩니다.
> - `data/raw/` 및 `data/processed/` 내 기존 데이터 파일은 임의로 파일명을 변경하거나 삭제하지 마십시오.

## 2. 전처리 가공 데이터 (`data/processed/`)

위례선 트램 개통 계획과 창곡동 일대 보행 접근성을 분석하여 생성된 공간 데이터(GeoJSON) 목록입니다.

| 파일명 | 형식 | 설명 |
| :--- | :--- | :--- |
| `wirye_changgok_boundary.geojson` | Polygon | 성남시 수정구 창곡동 행정구역 경계 |
| `wirye_tram_official_stations.geojson` | Point | 서울시 고시 및 대광위 사업계획 승인 위례선 트램 공식 12개 정거장 |
| `wirye_tram_official_lines.geojson` | LineString | 위례선 트램 본선(마천역~복정역) 및 지선(위례중앙~남위례역) 공식 노선 |
| `wirye_tram_buffer_700m.geojson` | MultiPolygon | 트램 정거장 기준 도보 10분(직선거리 700m) 서비스 권역 버퍼 |
| `wirye_tram_blindspot_700m.geojson` | MultiPolygon | 창곡동 구역 중 트램 700m 서비스 권역에서 제외된 대중교통 사각지대 |
| `wirye_vulnerable_apartments.geojson` | Point | 사각지대 내 위치한 주요 교통 취약 아파트 단지 정보 (단지명, 세대수 등) |
