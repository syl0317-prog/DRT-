# 6개 메뉴 통합 안내

## 실행

프로젝트 최상위 PowerShell에서 실행한다.

```powershell
python -B -m streamlit run drt_system/app.py
python -B -m unittest discover -s drt_system/tests -p 'test_*.py' -v
```

현재 설치된 Streamlit의 `st.iframe`과 기존 Streamlit/Altair/Folium 패키지를 사용한다. 추가 패키지는 설치하지 않았다.

## 기존 10개 기능 접근 경로

| 기존 기능 | 새 경로 |
|---|---|
| 운영 대시보드 | 통합 대시보드 |
| DRT 운행 지도 | 배차·경로 → 지도·노선 설정 |
| 예약 관리 | 예약 관리 |
| 트램 환승 관리 | 배차·경로 → 배차·픽업 계산 |
| 운영 시뮬레이션 | 운영 시뮬레이션 → 예약 기반 합승 |
| 정시성 검증 | 정시·환승 분석 → 기존 정시성 검증 |
| 정시성 및 트램 환승 분석 | 정시·환승 분석 → 개별 운행 분석 |
| 도로 혼잡도 분석 | 통합 대시보드 → 교통정보 상세 보기 → GITS 상세 분석 |
| 운영전략 비교 | 운영 시뮬레이션 → 운영전략 비교 |
| 관리자 패널 | 관리·설정 |

기존 GITS 매칭 HTML도 대시보드 하단의 `GITS 후보 지도`에서 볼 수 있다. 가장 최근 실행 폴더의 요약·후보 CSV·지도를 함께 읽고, 입력 파일 해시가 다르면 과거 결과 경고를 표시한다. 지도를 새로 생성하거나 원본을 수정하지 않는다.

## 대시보드 데이터 의미

상단 카드는 예약 파일의 `예약완료` 행 수와 승객 합계, 세션의 설정 차량 수, 유효 예약의 고유 차량 수이다. 승객 수가 잘못된 경우 합계를 추측하지 않는다. 예약에는 운행일자가 없으므로 오늘 예약이라고 표시하지 않는다. 배정 차량 수는 배차 완료나 실시간 운행 차량 수가 아니다.

중앙 개요 지도는 온라인 배경지도 위에 저장된 정류장·환승 거점만 표시하며 경로 요청, 클릭 위치 저장, 편집 기능이 없다. 배경지도와 Leaflet JS/CSS에는 인터넷이 필요하다. 실제 경유지·목적지 선택, 경로 계산, 거리·시간, 지도 클릭 위치 확인 및 정류장 표는 배차·경로에서 유지한다. 두 지도는 OSM 표준 배경을 기본으로 표시하고 레이어에서 OSM Deutschland를 선택할 수 있다. 로딩 실패·지연 안내가 있으며 타일 정책을 우회하지 않는다. 상세 내용은 `map_background_fix.md`를 참고한다.

정시·환승 요약은 이번 세션에서 실제 실행된 개별 운행 분석의 결과만 표시한다. 입력 경로·날짜·좌표·가상 트램 시각·분포·혼잡 증가율·시드·반복수·OSRM/수동 출처와 실행 시각을 함께 보관한다. 입력이 바뀌면 상세 화면에서 과거 결과를 숨기고 재실행을 요청한다. 대시보드에 남은 결과는 실행 당시 조건으로 표시한다. 실제 운영 실적과 합산하지 않는다.

예약 기반 합승, 기존 삼각분포 정시성 검증, 운영전략 비교는 각자의 최근 실행 조건과 결과를 별도로 보관한다. 비교 불가능한 결과를 평균하거나 하나의 정시율로 합치지 않는다. GITS는 여전히 운영 경로 비용에 적용하지 않는다.

## 모듈 구조와 보존

- `app.py`: 6개 주요 메뉴와 조건부 하위 화면 호출, 공통 스타일.
- `dashboard_views.py`: 읽기 전용 예약 집계, 정류장 지도, GITS 결과·출처, 연구 결과 요약, 이동 버튼.
- `operational_views.py`: 기존 app.py의 예약·배차·합승 UI를 옮겼다. 실제 알고리즘은 기존 reservation_manager/integrated_scheduler/pickup_scheduler/shared_route를 호출한다.
- `route_views.py`: 기존 map_view의 화면을 별도로 보존하고, 입력 상태 유지와 타일 없는 배경·진단 출력 정리만 적용했다. 기존 map_view.py는 그대로 둔다.
- `detail_views.py`: 기존 analysis_views/gits_views의 상세 화면을 별도 UI 모듈에 보존했다. 계산은 원래 punctuality_sim/strategy_sim 함수를 호출한다. 원래 팀원 모듈은 수정하지 않았다.
- `session_ui.py`: 위젯 입력을 별도 세션 사전에 보관하여 Streamlit의 숨겨진 위젯 정리 후에도 복원한다. 전역 Streamlit API를 monkey-patch하지 않는다. 실행 결과에는 입력 서명·출처·시각을 보관한다.
- `punctuality_views.py`: 계산 알고리즘은 그대로 호출하고, 입력·실행 결과의 세션 보관과 대시보드용 요약만 추가했다.

`st.tabs`를 사용하지 않고 선택한 하위 화면만 조건부로 호출한다. 개별 운행·예약 합승·배차는 실행 버튼을 눌렀을 때만 계산하며, 같은 입력으로 돌아오면 보관된 결과를 보여준다. 기존 정시성 검증·운영전략 비교는 해당 화면에 진입하여 조건이 달라졌을 때 원래 방식으로 계산하고, 동일 입력·데이터 버전의 결과를 재사용한다. 예약 생성·취소는 항상 명시적인 버튼 조작으로만 실행한다.

설정·입력·계산 결과는 현재 브라우저 세션 범위에서 유지되며 서버 재시작이나 새 세션까지 영구 보관되는 것은 아니다. 기존 CSV 저장·다운로드 기능은 그대로 제공한다.

## 검증

전체 자동 테스트 55개 통과. 새 메뉴 통합 테스트 7개는 다음을 확인한다.

- 6개 주요 메뉴와 기존 10개 기능 접근, GITS 상세 표·그래프·품질 및 후보 지도 접근.
- 대시보드 실제 집계, 잘못된 승객 수 처리, 6개 정류장과 온라인 배경이 있으며 경로 요청 없는 개요 지도.
- 원래 예약 알고리즘의 생성·조회·취소를 임시 예약 CSV에서 실행하고 대시보드 재집계 확인.
- 원래 배차·픽업·합승 계산을 고정된 테스트 경로 응답으로 실행하고 결과 확인.
- 메뉴 이동 후 입력·실행 결과 및 차량 수 유지, 이동 버튼 동작.
- 선택하지 않은 기존 정시성/전략 계산이 실행되지 않음.

기존 테스트는 실제 OSRM 캐시 읽기, 모의 온라인 성공·실패, 정시성·분포·자정 처리, V-World/GITS 회귀를 확인한다. 실제 외부 OSRM 온라인 서버 응답의 재현성을 검증한 것은 아니다.

로컬 Streamlit 서버를 127.0.0.1:8512에서 일시 기동해 루트와 health URL의 HTTP 200을 확인한 뒤 종료했다. 브라우저 연결 도구가 `The browser access host is unavailable`을 반환하여 픽셀 렌더링, 실제 브라우저 지도 클릭·차트 표시·콘솔 오류는 미검증이다. 원본 예약·데이터에 테스트 행을 저장하지 않았다. Git commit/push는 수행하지 않았다.
